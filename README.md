## 📖 项目简介

AutoFlow Studio 是一款**可视化桌面自动化工具**，采用节点编排的方式构建自动化工作流。无需编写代码，通过拖拽连接节点即可完成复杂的桌面自动化任务。

### ✨ 核心特性

- 🎨 **可视化编排** - 拖拽式节点编辑器，所见即所得
- 🖱️ **鼠标自动化** - 单击、双击、右键、移动、拖拽
- ⌨️ **键盘自动化** - 文本输入、快捷键组合
- 👁️ **视觉识别** - 找图、找文字、等待元素出现
- 🔀 **逻辑控制** - 循环、条件判断、分支执行
- 📦 **变量系统** - 全局变量存储与传递
- 🎬 **宏录制** - 录制操作序列并回放
- ⏰ **多种触发** - 手动、定时(Cron)、热键触发
- 🐛 **调试模式** - 逐节点执行，实时查看状态
- 🎭 **主题切换** - 深色/浅色主题支持
- 📄 **脚本导出** - 工作流可导出为 Python 脚本

## 🔧 工作流文件格式

工作流以 JSON 格式存储，扩展名为 `.af.json`：

```json
{
  "version": "0.1.0",
  "nodes": [
    {
      "id": "a1b2c3d4",
      "node_type": "flow.start",
      "label": "开始",
      "params": {},
      "pos_x": 100,
      "pos_y": 100
    },
    {
      "id": "b2c3d4e5",
      "node_type": "mouse.click",
      "label": "单击",
      "params": {
        "X": 500,
        "Y": 400,
        "button": "左键",
        "次数": 1
      },
      "pos_x": 350,
      "pos_y": 100
    }
  ],
  "connections": [
    {
      "source_node_id": "a1b2c3d4",
      "source_port_id": "out",
      "target_node_id": "b2c3d4e5",
      "target_port_id": "in"
    }
  ]
}
```

## ⚙️ 使用说明

### 主题切换

应用支持深色和浅色两种主题，可通过菜单栏 **视图 → 主题** 切换。

### 注意事项

- **管理员权限**：部分操作（如控制管理员运行的程序）需要以管理员身份运行 AutoFlow Studio
- **DPI 设置**：高 DPI 显示器下可能需要调整 Windows 显示设置
- **杀毒软件**：部分杀毒软件可能误报，需添加信任

## 最新版本更新内容

## 🆕 新增功能

### 1. 屏幕坐标抓取器
工具栏新增 **「📍 抓坐标」** 按钮（位于「提权重启」右侧）。点击后弹出全屏半透明遮罩，覆盖所有显示器（主屏+副屏），鼠标实时跟随显示十字准线和当前坐标值，左键点击即抓取坐标并**自动复制到剪贴板**，右键或 Esc 取消。

- 支持主屏+副屏全覆盖
- 径向半透明遮罩，桌面内容清晰可见
- 顶部居中操作提示栏
- 左下角标注屏幕分辨率

### 2. 所有 21 种节点的使用说明
点击任意节点后，属性面板下方新增**「使用说明」区块**，以 Markdown 格式渲染，面向新手详细解释每个节点的用法。

覆盖全部节点类型：手动触发、定时触发、热键触发、鼠标单击/双击/右键/移动/拖拽、文本输入、按键操作、找图、找字(OCR)、等待出现、开始、延时、循环、条件判断、设置变量、获取变量、ST 执行块、执行宏。

### 3. 定时任务 Cron → 时间选择器
定时触发节点不再需要手动输入 Cron 表达式，改为 **「小时 : 分钟」** 双重下拉框，选中时间自动生成 `分钟 小时 * * *` 表达式。已保存的旧工作流文件中的简单 cron 表达式会自动解析还原到下拉框。
