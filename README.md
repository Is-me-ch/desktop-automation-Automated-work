## 📖 项目简介

AutoFlow Studio 是一款**可视化桌面自动化工具**，采用节点编排的方式构建自动化工作流。无需编写代码，通过拖拽连接节点即可完成复杂的桌面自动化任务。

### ✨ 核心特性

- 🎨 **可视化编排** - 拖拽式节点编辑器，所见即所得
- 🖱️ **鼠标自动化** - 单击、双击、右键、移动、拖拽
- ⌨️ **键盘自动化** - 文本输入、快捷键组合
- 👁️ **视觉识别** - 找图、找文字、等待元素出现
- 🔀 **逻辑控制** - 循环、条件判断、分支执行
- 📦 **变量系统** - 全局变量存储与传递
- 🎬 **宏录制** - 录制操作序列并回放
- ⏰ **多种触发** - 手动、定时(Cron)、热键触发
- 🐛 **调试模式** - 逐节点执行，实时查看状态
- 🎭 **主题切换** - 深色/浅色主题支持
- 📄 **脚本导出** - 工作流可导出为 Python 脚本

## 📦 功能节点

### 触发器节点

| 节点 | 说明 |
|------|------|
| ▶ 手动触发 | 点击运行按钮启动工作流 |
| ⏰ 定时触发 | 使用 Cron 表达式定时执行 |
| ⌨ 热键触发 | 监听全局热键启动执行 |

### 鼠标节点

| 节点 | 说明 |
|------|------|
| 🖱 单击 | 在指定坐标执行鼠标单击 |
| 🖱 双击 | 在指定坐标执行鼠标双击 |
| 🖱 右键 | 在指定坐标执行右键单击 |
| 🖱 移动 | 移动鼠标到指定坐标 |
| 🖱 拖拽 | 从起点拖拽到终点 |

### 键盘节点

| 节点 | 说明 |
|------|------|
| ⌨ 输入文本 | 模拟键盘输入指定文本 |
| ⌨ 按键 | 模拟按下指定键(支持组合键) |

### 视觉识别节点

| 节点 | 说明 |
|------|------|
| 🔍 找图 | 在屏幕中查找匹配的图片 |
| 🔍 找文字 | OCR识别屏幕中的文字 |
| 🔍 等待出现 | 等待指定图片/文字出现 |

### 逻辑控制节点

| 节点 | 说明 |
|------|------|
| 🔄 循环 | 支持固定次数和条件循环 |
| 🔀 条件判断 | If-Else 分支控制 |
| 🔀 执行块 | 结构化执行子流程 |

### 变量节点

| 节点 | 说明 |
|------|------|
| 📦 设置变量 | 定义或更新变量值 |
| 📦 获取变量 | 读取变量值 |

### 流程控制节点

| 节点 | 说明 |
|------|------|
| ▶ 开始 | 工作流起始节点 |
| ⏱ 延时 | 等待指定时间后继续 |

## 🔧 工作流文件格式

工作流以 JSON 格式存储，扩展名为 `.af.json`：

```json
{
  "version": "0.1.0",
  "nodes": [
    {
      "id": "a1b2c3d4",
      "node_type": "flow.start",
      "label": "开始",
      "params": {},
      "pos_x": 100,
      "pos_y": 100
    },
    {
      "id": "b2c3d4e5",
      "node_type": "mouse.click",
      "label": "单击",
      "params": {
        "X": 500,
        "Y": 400,
        "button": "左键",
        "次数": 1
      },
      "pos_x": 350,
      "pos_y": 100
    }
  ],
  "connections": [
    {
      "source_node_id": "a1b2c3d4",
      "source_port_id": "out",
      "target_node_id": "b2c3d4e5",
      "target_port_id": "in"
    }
  ]
}
```

## 📋 内置模板

| 模板 | 说明 | 分类 |
|------|------|------|
| 点击元素 | 在指定坐标执行鼠标单击 | 鼠标操作 |

| 快捷键组合 | 执行 Ctrl+C 等组合键 | 键盘操作 |
| 表单填写 | 自动填写表单 | 综合流程 |
| 文件下载 | 自动化下载流程 | 综合流程 |

## ⚙️ 使用说明

### 主题切换

应用支持深色和浅色两种主题，可通过菜单栏 **视图 → 主题** 切换。

### 注意事项

- **管理员权限**：部分操作（如控制管理员运行的程序）需要以管理员身份运行 AutoFlow Studio
- **DPI 设置**：高 DPI 显示器下可能需要调整 Windows 显示设置
- **杀毒软件**：部分杀毒软件可能误报，需添加信任
